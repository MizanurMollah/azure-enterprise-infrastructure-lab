# 05 — Azure SQL Database

## Objective
Provision a small Azure SQL Database and document secure connectivity.

## Tasks
- Create an Azure SQL logical server/database using the smallest practical lab configuration.
- Configure networking carefully.
- Test connectivity only from an allowed location/workload.
- Remove or scale down the database when finished.

## Evidence
- [ ] SQL server
- [ ] Database
- [ ] Networking/firewall
- [ ] Successful test

## Security note
Never commit database passwords or connection strings.

## Interview questions
- Azure SQL Database vs SQL Server on an Azure VM?
- What is a logical server?
- What is a firewall rule?
