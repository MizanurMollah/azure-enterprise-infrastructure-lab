# 03 — Virtual Machine

## Objective
Deploy and administer a small Azure VM.

## Tasks
- Deploy a small supported VM size suitable for your subscription.
- Place it in the App subnet.
- Apply an NSG.
- Enable boot diagnostics if required.
- Connect and verify the operating system.
- Stop/deallocate the VM when not practicing.
