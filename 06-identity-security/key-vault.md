# 06 — Azure Key Vault

## Objective
Store a lab secret securely instead of putting it in source code.

## Tasks
- Create a Key Vault.
- Add a non-sensitive test secret.
- Review access control.
- Retrieve the secret through the portal/CLI for practice.
- Delete the test secret after the exercise if appropriate.
