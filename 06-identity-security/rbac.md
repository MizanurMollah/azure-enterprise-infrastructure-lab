# 06 — Azure RBAC

## Objective
Apply least-privilege access using Azure role-based access control.

## Tasks
- Review Owner, Contributor and Reader roles.
- Assign the least privilege required for a test user/group.
- Record the scope: management group, subscription, resource group or resource.
- Remove temporary access after testing.

## Evidence
- [ ] Role assignment
- [ ] Scope
- [ ] Access verification
