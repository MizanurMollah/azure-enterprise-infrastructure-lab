# 02 — Azure Virtual Network

## Objective
Build a basic enterprise-style network layout.

## Suggested design
- VNet: `vnet-azlab-prod`
- Address space: `10.10.0.0/16`
- App subnet: `10.10.1.0/24`
- Data subnet: `10.10.2.0/24`

## Tasks
- Create the VNet.
- Create App and Data subnets.
- Verify effective address ranges.
- Document why application and data workloads should be separated.
